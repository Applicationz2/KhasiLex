# Batch 003 — independent 1968 source retrieval audit (2026-11-20)

## Discovery

The independently authored 1968 *Ka Dienshonhi* by Iarington Kharkongor is documented in the source digitization repository at https://github.com/udaycruise2903/khasi-dienshonhi . Its README identifies a 493-page Digital Library of India scan (barcode 07019990352114; historical handle 2015/464423) held at State Central Library, Shillong. The project's public GitHub tree contains README, cleaning scripts, conversion scripts, and sample Y-line spreadsheets, **not the full 8,400+ entry XML or searchable A-headword corpus**. The landing page https://udaycruise2903.github.io/khasidrp/dictionary/ reports OCR and transcription limitations. Consequently this resource is **bibliographically identified, not independently entry-verified** for the 20 candidates.

The Khasi Authors Society bibliography https://khasiauthorssociety.org/ka-seng-ka-don-artylli-ki-kot-journals-kiba-ka-ju-pynmih-tista-man-la-ka-snem/ separately lists Iarington Kharkongor's 1968 dictionary and E. Bars's 1973 *Khasi-English Dictionary*. A bibliography listing does not establish an entry or sense.
