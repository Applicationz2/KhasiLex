# User-provided source evaluation — v0.4

This note records the editorial treatment of three resources supplied for KhasiLex vocabulary expansion.

## 1. U Nissor Singh, *Khasi-English Dictionary* (1906)

User link: Scribd scan titled `Khasi-English Dictionary`.

KhasiLex canonical source: the same 1906 work hosted by Wikimedia Commons / Internet Archive as a public-domain scan.

- Author: U Nissor Singh
- Editors: Major P. R. T. Gurdon, U Dohory Ropmay, U Hajom Kissor Singh
- Publication: Shillong, Eastern Bengal and Assam Secretariat Press, 1906
- Status: **approved historical lexical source**
- Rights treatment: public domain scan used as the canonical ingestion source
- Permitted use: headwords, historical English glosses, grammatical labels and historical usage evidence
- Editorial caution: spelling, sense, register and modern standard usage must be reviewed by a Khasi editor before promotion to `verified`
- Dialect note: the author's preface states that the Cherra dialect was selected as the standard basis used in the dictionary, with words from other dialects included only rarely.

The Scribd upload is retained only as a discovery/reference URL. KhasiLex should ingest from the public-domain Commons/Internet Archive copy instead.

## 2. Glosbe English–Khasi / Khasi–English

- Type: community dictionary + translation memory + automatic translation interface
- Status: **reference-only / secondary cross-check**
- Strength: useful for discovering possible current translations and contextual examples
- Risk: entries come from multiple sources, community submissions and algorithmic translations; quality and per-entry provenance vary
- Import policy: do not bulk-import definitions or examples into KhasiLex. A Glosbe result may corroborate a candidate, but the underlying source and Khasi linguistic correctness must still be reviewed.

Examples observed during source evaluation include `balei` ↔ `why`, `jngi` ↔ `swim`, `lano` among translations of `when`, and `ban` ↔ `to`. These are stored only as cross-check evidence, not as automatic verification.

## 3. Webtran English–Khasi translator

- Type: online machine-translation service
- Status: **reference-only / candidate generator**
- The public page provides an interactive translator rather than a reusable downloadable lexical corpus.
- Import policy: do not scrape or bulk-ingest output as dictionary truth. Individual outputs may be tested as candidate translations and must undergo the normal KhasiLex human review process.

## Editorial rule

Historical dictionaries, community dictionaries and machine translators are complementary evidence sources, not automatic authorities. KhasiLex `verified` status still requires canonical spelling, grammatical analysis, a Khasi definition, provenance, licence/permission status, reviewer identity and review date.
