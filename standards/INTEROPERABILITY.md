# Interoperability Targets

KhasiLex is architected to interoperate with:

- BCP 47 language tags
- Unicode / NFC
- Unicode CLDR-style locale metadata
- ISO 24613 Lexical Markup Framework concepts
- TMX translation memory
- TBX terminology exchange concepts
- TEI dictionary encoding
- W3C OntoLex-Lemon / linked lexical data
- JSON / JSONL / JSON-LD
- CSV / TSV
- REST / OpenAPI

Draft exporters are engineering interoperability targets. Formal standards conformance should be validated before claiming certification.
