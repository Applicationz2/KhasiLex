# KhasiLex Reviewer Roles

KhasiLex uses role separation so that lexical quantity never outruns linguistic quality.

## Lexical editor

Checks canonical spelling, headword selection, variants, lexical category, definitions, semantic relations, idioms and multiword expressions.

## Grammar reviewer

Checks part of speech, grammatical behavior, agreement information, derivation, reduplication, syntax notes and example-sentence grammaticality.

## Translation reviewer

Checks foreign-language glosses and equivalents against the intended Khasi sense. Translation review must be sense-aware, not string-to-string substitution.

## Provenance reviewer

Checks source attribution, reuse permission/licence, copyright status and evidence references.

## Technical reviewer

Checks identifiers, Unicode NFC, schemas, build outputs, validation, API compatibility and release reproducibility.

## Verification rule

An entry may be marked `verified` only after it satisfies the v0.4 validator and corpus audit. For higher-stakes or disputed entries, independent lexical and grammar review is preferred.

AI systems may assist any role with candidate material, but they cannot self-approve an entry.
